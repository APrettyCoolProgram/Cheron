This folder structure is for individual **projects** in a repository.

You'll notice there are several files/folders that exist in the repository root but are not included in individual projects:

## .github/

* `agents/`  
  By default, projects use the repository-level agents.

* archive/  
  By default, projects use the repository-level archive.

* development/old-src
  By default, projects use the repository-level development/old-src.

## Other files

You'll notice the following files are not included in **projects**, because the repository has these files already. In the event that a project needs it's own file, you can create it.

* .gitignore
* AGENTS.md
* LICENSE
